A compact wearable device designed for cattle health monitoring. The device continuously tracks vital parameters such as heart rate and body temperature, with data transmitted wirelessly via Wi-Fi for remote monitoring and analysis.

![Screenshot 2024-11-06 193350](https://github.com/user-attachments/assets/80d2c792-0164-4dbe-a42c-053a32d6b9fa)

Specs : 
- TTGO T7.
- Built-in GPS, Heart Rate sensor, Temperature sensor, and Gyroscope sensor.
- 3000mAh 3.7v Battery.
